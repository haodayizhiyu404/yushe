# 预设助手（yushe）

> 原名「剧情编年史」，v3.1 起更名「预设助手」。

挂在**酒馆助手（JS-Slash-Runner）预设脚本库**上的剧情辅助脚本——不是独立扩展，跟着预设走，**随预设一起导出/导入**。

- `main.js` — 代码主体（无需手动操作，加载器自动拉取）
- `loader.js` — 加载器，**唯一需要粘贴进酒馆助手的文件**

## 安装

1. 确保已安装酒馆助手扩展
2. 酒馆 → 扩展 → 酒馆助手 → **预设脚本库** → 新建脚本 → 粘贴 `loader.js` 全文 → 保存
3. 按钮栏自动出现「🧰 预设助手」

每次打开页面，加载器自动从本仓库 main 分支拉取最新 `main.js` 执行；拉取失败时用本地缓存版本兜底。

## 界面

单面板 + 左侧导航四页，纸张感浅色阅读主题，面板右上角可切换 **☀️ 日 / 🌙 夜**（选择存本地，不随预设导出）。

| 页面 | 作用 |
|---|---|
| 📜 总结 | 查看/编辑大总结，立即总结、重新总结、撤销、清空 |
| 🧭 规划 | 剧情催化：风格快捷提案 + 多轮讨论，采纳「近期走向」注入正文 depth 0 |
| 🔀 切换 | 各组互斥条目选项（当前激活高亮），点击即切换 |
| ⚙️ 设置 | 全部设置收拢于此，**改动自动保存**，仅保留恢复默认按钮 |

## 设计理念

脚本**不自己拼装上下文**。预设的 chatHistory / 世界书 / 角色卡占位符天然携带全部上下文，总结时只做三件事：

1. 临时点亮预设里的「大总结」提示词条目
2. 调 `generate()`，在末尾追加一条 user 触发消息（默认「生成大总结」）
3. 把结果存入聊天变量、注入聊天顶部（in_chat, depth 9999）、隐藏已总结楼层

## 使用前提（预设作者负责）

预设里需要两个**默认关闭**的提示词条目：

**1. 总结条目**（如「📢大总结」），内容写明触发前提，例如：

```
当User发送“生成大总结”或“总结前文”时，暂停正文叙事，只输出大总结。
（后接你的总结格式要求……）
```

**2. 规划条目**（如「🧭剧情规划」），内容写明策划人设 + 输出契约，例如：

```
当User与你进行剧情规划讨论时，暂停正文叙事。你是本故事的剧情策划，
完整了解当前剧情与设定，结合作者的想法给出意外但合理的后续走向建议。

【输出契约】
· 日常讨论（分析、闲聊、头脑风暴）直接输出，不要使用任何标签。
· 当你给出正式的、可供正文采纳的走向方案时，必须将方案完整放入
  <剧情走向> 与 </剧情走向> 之间，标签外可附简短说明。
· 走向方案以剧情趣味性为第一要素，时间尺度由题材自行决定；
  事件要具体可演、有连锁反应，能引入新张力但不摧毁现有关系基础。
```

- 条目的 **ID 或名称**需与设置中的对应项一致（默认 `📢大总结` / `🧭剧情规划`）
- 规划条目里的标签名需与设置中的「走向模块标签名」一致（默认 `剧情走向`）
- 条目找不到时操作会直接弹报错，不会静默失败

## 剧情规划（剧情催化）说明

定位不是"全局大纲"，而是**近期剧情催化剂**：僵局/平淡期让 AI 设计一个具体意外展开，趣味性第一、时间尺度由题材决定，演完即弃。

- **🎲 快速提案**：点风格按钮，按设置里的「风格提案模板」发出方向指令（`{{风格}}` 占位）
- **讨论区**：AI 能看到全部讨论记录（上限 40 轮）和当前剧情全文；每条气泡可 ✕ 单删，最后一条策划回复可 ⟳ 重 roll
- **发送键三态**：有字=发新消息；空+末尾是自己的消息=♻️重新生成；空+末尾是 AI 回复=置灰。生成失败时消息留在末尾，点发送即重试
- **📌 采纳走向**：从最近一条含 `<剧情走向>` 模块的回复中只提取标签内容录入（闲聊部分不进注入）
- **✅ 已演完**：走向上演完一键撤掉注入

## 快速切换配置

在「⚙️ 设置」里按此格式配置（一行一条，同组内选项互斥）：

```
破限 | 常规 = ◈==破限越狱==◈
破限 | Lumi = 🌟拟人, 🌠故事法则
```

## 数据存在哪

| 数据 | 存储位置 | 生命周期 |
|---|---|---|
| 设置项（条目名、触发词、风格列表、切换配置等） | **预设变量** | 随预设导出，换聊天不丢 |
| **API 配置（URL / Key / 模型名）** | **全局变量** | 只存在当前用户本地，**不随预设导出** |
| 大总结 / 总结进度 / 历史版本 / 近期走向 / 讨论记录 | **聊天变量** | 跟着聊天存档走，开新档自动归零 |
| 脚本代码缓存（加载器兜底用） | **全局变量** | 只存本地，每次成功拉取后更新 |
